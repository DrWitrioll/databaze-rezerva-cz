# Databáze – Rezervní posádka

Zdrojový repozitář pro web **databaze-rezerva-cz.vercel.app**.

Projekt slouží jako databáze světa a kánonu příběhu **Rezervní posádka / NII**. Web používá média uložená v Cloudinary pod projektem `rezervni-posadka` a je určený k nasazení přes Vercel.

## Produkce

- Web: https://databaze-rezerva-cz.vercel.app/
- Hosting: Vercel
- Média: Cloudinary
- Zdrojový kód: GitHub
